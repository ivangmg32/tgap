## Models (display names)

| Technical id | Display name | Reads | Calculates |
|---|---|---|---|
| `persistence_bridge` (Present · bridge width) | Bridge Width — Current Snapshot | only the latest snapshot | the number of connections between the two communities in the latest snapshot |
| `trend_bridge` (Forecast · bridge width) | Bridge Width — Next-Step Forecast | every snapshot (the whole history) | a straight-line fit of bridge width over time, extended one step into the future |
| `slope_bridge` (Trajectory · bridge slope) | Bridge Width — Historical Slope | every snapshot (the whole history) | the slope of the straight-line fit of bridge width over time |
| `persistence_density` (Present · density) | Network Density — Current Snapshot | only the latest snapshot | the share of possible connections that exist in the latest snapshot |
| `persistence_centralization` (Present · centralization) | Network Centralization — Current Snapshot | only the latest snapshot | how strongly connections concentrate on a few hubs in the latest snapshot (Freeman degree centralization) |
| `trend_clustering` (Forecast · clustering) | Clustering — Next-Step Forecast | every snapshot (the whole history) | a straight-line forecast of the average clustering coefficient |
