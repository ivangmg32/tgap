# TGAP documentation

Use this page as a reading path. Start with the setup steps, then choose the
guide that matches your next task. The research reports and technical audits
are reference material; you do not need them to install or use TGAP.

## First time using TGAP

1. [Install the workbench](12-installation-and-self-hosting.md) — set up TGAP,
   start it, and run your first example.
2. [Follow an experiment from input to explanation](05-TGAP-worked-example-trace.md)
   — see a complete worked example.
3. [Read the complete guide](06-TGAP-complete-guide-A-to-Z.md) for the concepts
   behind the workflow.
