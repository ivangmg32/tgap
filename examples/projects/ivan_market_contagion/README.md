# Ivan 4 - Contagion between sectors

Ivan's correlation networks as a TGAP temporal graph, a custom model
(`ContagionForecast`, model.py) and a custom concept (`SectorDecoupling`,
concept.py). The tutorial also checks that the custom concept and the
built-in Bridge Width - mirror images - give opposite signs.

```sh
python examples/projects/ivan_market_contagion/main.py
```

Outputs in `output/`: `TUTORIAL.md`, explanation, sensitivity and graph files.
