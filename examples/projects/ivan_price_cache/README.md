# Ivan 1 - Prices, returns and risk with Ivan's Cache

How Ivan's `Cache.py` provides prices (downloaded once, then offline), and how
prices become the daily returns every correlation network is built from.

```sh
python examples/projects/ivan_price_cache/main.py
```

Outputs in `output/`: `TUTORIAL.md`, `prices.csv`, `returns.csv`,
`risk_summary.csv`, `growth.png`, `volatility.png`.
